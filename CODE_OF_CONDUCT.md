# Código de Conduta

Este projeto adota o [Contributor Covenant, versão 2.1](https://www.contributor-covenant.org/pt-br/version/2/1/code_of_conduct/).

Em resumo: seja respeitoso, acolhedor e construtivo. Assédio, ataques pessoais, linguagem discriminatória e divulgação de informações privadas de terceiros não são tolerados em issues, PRs, discussões ou qualquer outro espaço do projeto.

## Como relatar

Relate comportamentos inaceitáveis de forma privada ao mantenedor pelo GitHub ([@Efer-Eder](https://github.com/Efer-Eder)). Os relatos serão tratados com confidencialidade e respondidos o quanto antes.

## Aplicação

O mantenedor pode remover, editar ou rejeitar comentários, commits, código, issues e outras contribuições que violem este código, e pode banir temporária ou permanentemente quem o fizer, seguindo as diretrizes de aplicação do Contributor Covenant 2.1.
